# Sour Optic — Frontend

React 19 + Vite + TypeScript frontend for the Sour Optic optometrist practice management platform.

This repository is a placeholder scaffold. The application is initialized in **Task 15 — Frontend
project initialization** and built out through the frontend feature tasks. See the workspace
`tasks/` directory for the ordered plan.

## Stack (target)

- React 19 + Vite + TypeScript
- TanStack Router / Query / Form
- shadcn/ui on Base UI primitives, lucide-react
- Tailwind CSS v4 with theme tokens
- EN/AR i18n with full RTL

Conventions are authoritative in `AGENTS.md` (added during Task 15).
